# FB Vacancy Bot

Мультиакк софт для автоматической рассылки вакансий в Facebook группы.

## Возможности
- Управление аккаунтами Facebook (добавление, прокси, прогрев, бан-детект)
- Парсинг и добавление групп по трудоустройству
- Создание и редактирование вакансий (текст + фото)
- Многопоточная рассылка в группы
- Веб-интерфейс для удалённого управления
- Статистика и уведомления

## Быстрый старт
```bash
pip install -r requirements.txt
python run.py
```
